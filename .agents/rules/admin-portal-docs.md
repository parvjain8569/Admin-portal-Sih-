# Admin Portal Documentation Maintenance Rule

Whenever any modification, feature addition, bug fix, or style change is made to the `Admin Portal/` directory:

You **MUST ALWAYS** update the following documentation files in the same response:
1. `Admin Portal/NOTES.md` & `Admin Portal/notes.txt` — update file table, component list, or architectural descriptions if files or structures changed.
2. `Admin Portal/AI_NOTES.md` — log latest work accomplished, technical decisions, and scenario notes.
3. `Admin Portal/PROJECT_CONTEXT.md` — keep feature descriptions, demo scenarios, and tech stack in sync.
4. `Admin Portal/README.md` — ensure quickstart instructions, credentials, and feature lists match active implementation.
5. `Admin Portal/GIT_PUSH_GUIDE.md` — ensure teammate commands and tracked files remain accurate.

**Never** leave these documentation files out of sync with code changes.
